# MicroGroq

MicroGroq is a lightweight chatbot inspired by Grok. It improves prompts, remembers previous conversations, plans actions, searches the web for relevant resources, analyzes errors in programs, and attempts to repair or suggest fixes.

## Features
- Improves and refines user prompts for better responses
- Maintains conversational context across interactions
- Plans multi-step actions to accomplish user tasks
- Searches the web and surfaces relevant resources and websites
- Analyzes errors in programs and suggests or applies fixes
- Provides concise, respectful output and explanations

## Context
MicroGroq was created to provide a compact, privacy-conscious assistant that helps developers and power users by refining prompts, planning actionable steps, locating helpful resources, and diagnosing and repairing code. It is intended as a minimal, extensible starting point for experimentation and learning rather than a production-ready service.
